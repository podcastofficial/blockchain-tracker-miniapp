# Blockchain Tracker

## Frontend Phase 1
- Binance-inspired dark responsive dashboard.
- 11 navigable modules.
- 10 blockchain network selectors.
- Local wallet and contract watchlist.
- Chain-aware address format validation and duplicate detection.
- Local alert-rule drafts.
- CSV export of local watchlist.
- Telegram Web App initialization.

## Important
This is the frontend foundation, not a live blockchain tracker yet. Live balances, prices, transaction history, token scanner results, whale events, DeFi metrics, Telegram delivery, subscriptions, API keys and admin operations require backend APIs, provider integrations and background workers. The UI intentionally does not invent live data.

## Run
Open `index.html` in a browser or deploy this folder as a static site. Configure the HTTPS Mini App URL in BotFather for Telegram deployment.
